# AERIS - ระบบคำนวณ BTU และจองบริการเครื่องปรับอากาศ 3D

โปรเจกต์ AERIS เป็นแพลตฟอร์ม E-Commerce เต็มรูปแบบสำหรับการซื้อ-ขายและบริการด้านเครื่องปรับอากาศ (HVACR) ที่มาพร้อมกับระบบจำลองห้อง 3D (Three.js) เพื่อช่วยลูกค้าคำนวณหาขนาด BTU ที่เหมาะสมแบบเรียลไทม์ และระบบ Backend สำหรับจัดการ Authentication และบันทึกการจองบริการ

## 🌟 ฟีเจอร์หลัก (Key Features)

*   **ระบบ Authentication แบบครบวงจร**: รองรับการสมัครสมาชิกและเข้าสู่ระบบของลูกค้าทั่วไปด้วยการเข้ารหัสผ่าน (Bcrypt) และ JWT Token รวมถึงหน้าเข้าสู่ระบบแยกเฉพาะสำหรับผู้ดูแลระบบ (Admin)
*   **3D Room Simulator & BTU Calculator**: ระบบจำลองห้อง 3D ที่สามารถโต้ตอบได้ (Interactive) ผู้ใช้สามารถปรับขนาดกว้าง ยาว สูง ระบุทิศทางการโดนแดด และจำนวนคนในห้อง เพื่อให้ระบบคำนวณ BTU และแนะนำรุ่นแอร์ที่แมตช์ที่สุด
*   **ระบบแคตตาล็อกสินค้า**: กรองสินค้าหมวดหมู่แอร์ติดผนังและแอร์ฝังฝ้าเชิงพาณิชย์
*   **ระบบจัดการนัดหมาย (Booking System)**: ฟอร์มรับข้อมูลจองบริการติดตั้ง ล้าง หรือซ่อมแอร์ โดยจะบันทึกข้อมูลลงฐานข้อมูล MongoDB
*   **ระบบแจ้งเตือนอีเมล (Email Notifications)**: ยืนยันการจองอัตโนมัติผ่านการเชื่อมต่อกับ Google Apps Script Webhook

## 💻 วิธีการใช้งานเว็บไซต์ (How to Use)

### 1. การเข้าสู่ระบบ (Login & Registration)
หน้าแรกสุดของเว็บไซต์จะบังคับให้ผู้ใช้ระบุตัวตนก่อนเข้าใช้งาน
*   **ลูกค้าทั่วไป**: หากยังไม่มีบัญชี ให้กด "ลงทะเบียนที่นี่" เพื่อสร้างบัญชีใหม่ด้วย ชื่อ, อีเมล และรหัสผ่าน ระบบจะบันทึกข้อมูลและสามารถใช้ล็อกอินเข้าสู่หน้าหลักได้ทันที
*   **ผู้ดูแลระบบ (Admin)**: สลับไปที่แท็บ "ผู้ดูแลระบบ" และใช้รหัสพนักงานที่ได้รับสิทธิ์ในการเข้าสู่ระบบ

### 2. การใช้งาน 3D Simulator (หาขนาดแอร์ที่ใช่)
*   ไปที่เมนู **จำลองห้อง 3D**
*   ลาก Slider หรือพิมพ์ตัวเลขเพื่อปรับความกว้าง ความยาว และความสูงของเพดานห้อง (โมเดล 3D จะปรับสเกลตามอัตโนมัติ)
*   เลือกปริมาณแสงแดดที่ส่องเข้าห้อง และปรับเพิ่ม/ลดจำนวนคนในห้อง
*   ระบบจะประมวลผลคำนวณปริมาตรห้องและแสดงค่า **BTU ที่เหมาะสม** ทันที พร้อมแสดงการ์ดสินค้ารุ่นที่สเปกผ่านเกณฑ์ให้เลือกซื้อด้านล่าง

### 3. การจองบริการ (Service Booking)
*   ไปที่เมนู **บริการ**
*   กรอกรายละเอียดในฟอร์ม "นัดหมายบริการ" (ชื่อ-นามสกุล, เบอร์โทรศัพท์, บริการที่ต้องการ, และรายละเอียดเพิ่มเติม)
*   เมื่อกดปุ่ม "ส่งคำขอนัดหมาย" ระบบ Frontend จะยิง API ไปที่ Backend เพื่อบันทึกข้อมูลลง Database
