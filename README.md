AERIS - ระบบคำนวณ BTU และจองบริการเครื่องปรับอากาศ 3Dโปรเจกต์ AERIS เป็นแพลตฟอร์ม E-Commerce เต็มรูปแบบสำหรับการซื้อ-ขายและบริการด้านเครื่องปรับอากาศ (HVACR) ที่มาพร้อมกับระบบจำลองห้อง 3D (Three.js) เพื่อช่วยลูกค้าคำนวณหาขนาด BTU ที่เหมาะสมแบบเรียลไทม์ และระบบ Backend สำหรับจัดการ Authentication และบันทึกการจองบริการ  🌟 ฟีเจอร์หลัก (Key Features)ระบบ Authentication แบบครบวงจร: รองรับการสมัครสมาชิกและเข้าสู่ระบบของลูกค้าทั่วไปด้วยการเข้ารหัสผ่าน (Bcrypt) และ JWT Token รวมถึงหน้าเข้าสู่ระบบแยกเฉพาะสำหรับผู้ดูแลระบบ (Admin)  3D Room Simulator & BTU Calculator: ระบบจำลองห้อง 3D ที่สามารถโต้ตอบได้ (Interactive) ผู้ใช้สามารถปรับขนาดกว้าง ยาว สูง ระบุทิศทางการโดนแดด และจำนวนคนในห้อง เพื่อให้ระบบคำนวณ BTU และแนะนำรุ่นแอร์ที่แมตช์ที่สุดระบบแคตตาล็อกสินค้า: กรองสินค้าหมวดหมู่แอร์ติดผนังและแอร์ฝังฝ้าเชิงพาณิชย์ระบบจัดการนัดหมาย (Booking System): ฟอร์มรับข้อมูลจองบริการติดตั้ง ล้าง หรือซ่อมแอร์ โดยจะบันทึกข้อมูลลงฐานข้อมูล MongoDB  ระบบแจ้งเตือนอีเมล (Email Notifications): ยืนยันการจองอัตโนมัติผ่านการเชื่อมต่อกับ Google Apps Script Webhook  💻 วิธีการใช้งานเว็บไซต์ (How to Use)1. การเข้าสู่ระบบ (Login &
